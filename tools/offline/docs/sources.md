# Research sources

References for the method. No source datasets or experimental results are
included in this tool directory. Consult each source's publication date before
using it to choose an experiment.

| Source | Contribution |
|---|---|
| [TREC 2025, NIST](https://www.nist.gov/publications/34th-text-retrieval-conference-trec-2025) and [RAG track](https://trec.nist.gov/pubs/trec34/papers/Overview_rag.pdf) | Evaluation infrastructure, tasks, judgments, and downstream quality |
| [NIST on pooling bias](https://www.nist.gov/publications/bias-and-limits-pooling-large-collections) | Diverse pools and incomplete-judgment checks |
| [trec_eval](https://github.com/usnistgov/trec_eval) | Scoring reference; full parity is not yet verified |
| [BEIR](https://github.com/beir-cellar/beir) | Heterogeneous tasks and lexical/dense baselines |
| [BRIGHT](https://brightbenchmark.github.io/) | Reasoning-intensive retrieval |
| [Lean Finder V2, October 2026](https://arxiv.org/html/2610.30843v2) | Ambiguity, concise queries, rewriting, context, downstream proving |
| [LeanSearch v2, May 2026](https://arxiv.org/html/2605.13137v2) | Search, premise groups, and proving; MathlibQR and MathlibMPR |
| [LeanGraphSearch, October 2026](https://arxiv.org/abs/2610.22339) | Dependency-graph retrieval and downstream proof utility |
| [Loogle](https://github.com/nomeata/loogle) | Symbolic search baseline |
| [Sadowski et al., 2015](https://research.google.com/pubs/archive/43835.pdf) | Code-search logs and surveys |
| [Soboroff, 2025](https://www.nist.gov/publications/dont-use-llms-make-relevance-judgments) | Objections to replacing human judges with LLMs |
| [Upadhyay et al., 2025](https://www.nist.gov/publications/large-scale-study-relevance-assessments-large-language-models-initial-look) | Large-scale assessment-method comparison |
| [Urbano et al., SIGIR 2019](https://arxiv.org/abs/1905.11096) | Empirical evidence on IR significance tests |
| [Kohavi et al., KDD 2007](https://ai.stanford.edu/~ronnyk/GuideControlledExperiments.pdf) | Controlled experiments, power, causal interpretation |
